# Student Score Prediction System 🎓

An AI/ML-based Student Score Prediction System that predicts student academic performance using factors such as study hours, attendance, previous scores, and other academic features.

## 🚀 Features

- Student performance prediction
- Study hours and attendance analysis
- Machine Learning regression model
- R², MAE and RMSE evaluation
- Simple prediction interface
- Frontend + Backend architecture

## 🛠️ Technologies Used

- Python
- Machine Learning
- HTML
- CSS
- JavaScript
- FastAPI/Flask
- GitHub

## 📊 Prediction Factors

The system uses academic factors such as:

- Study Hours
- Attendance
- Previous Scores
- Academic Performance
- Other relevant student features
